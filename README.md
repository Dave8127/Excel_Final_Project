# 📊 Retail Sales Analysis Dashboard

### Excel-Based Data Analysis Project

------------------------------------------------------------------------

## 📌 Project Overview

This project explores a retail sales dataset using Microsoft Excel. It
transforms transaction-level data into a structured analysis workbook,
highlighting sales performance, customer behaviour, product demand, and
regional trends.

The workbook combines formula-based analysis, PivotTables, scenario
modelling, linear regression, and an interactive dashboard to support
data-driven decision-making.

## 🎯 Project Objectives

-   Measure overall sales performance through key performance indicators
    (KPIs).
-   Compare revenue across regions, product categories, and individual
    products.
-   Identify frequently purchased products and high-value customers.
-   Explore monthly sales patterns.
-   Use scenario analysis to understand the impact of changing sales
    quantities.
-   Apply linear regression to examine relationships within the dataset.
-   Present important findings through a consolidated dashboard.

## 🗂️ Workbook Structure

  -----------------------------------------------------------------------
  Worksheet                           Description
  ----------------------------------- -----------------------------------
  **Dataset**                         Raw retail transaction records,
                                      including dates, customers,
                                      products, quantities, prices,
                                      payment methods, regions, and
                                      customer segments.

  **Analysis**                        KPI calculations, Goal Seek,
                                      revenue breakdowns, product
                                      purchase frequency, and customer
                                      ranking.

  **Linear Regression**               Regression output and statistical
                                      measures used to examine
                                      relationships in the data.

  **Scenario Summary**                Comparison of low-sale,
                                      expected-sale, and high-sale
                                      scenarios.

  **Pivot Table**                     Summarised sales by region,
                                      product, and month.

  **DashBoard**                       Visual overview of key metrics and
                                      sales comparisons.
  -----------------------------------------------------------------------

## 🧰 Tools & Excel Features

-   **Microsoft Excel**
-   Excel formulas and functions: `SUM`, `AVERAGE`, `COUNTIF`, `SUMIFS`,
    `IF`, `RANK.EQ`
-   KPI calculations
-   Goal Seek
-   Scenario Manager
-   PivotTables
-   Linear Regression (Data Analysis ToolPak)
-   Charts and dashboard visualisation
-   Slicers for interactive filtering

## 📈 Key Analysis Areas

### 1. Sales Performance

-   Total revenue
-   Total transactions
-   Total quantity sold
-   Average transaction value

### 2. Revenue Analysis

-   Revenue by region
-   Revenue by product category
-   Revenue by individual product
-   Monthly sales trends

### 3. Customer Analysis

-   Customer-wise purchase totals
-   Customer ranking
-   Identification of high-value and regular customers

### 4. Product Analysis

-   Product purchase frequency
-   Comparison of product revenue
-   Identification of popular products

### 5. What-If & Statistical Analysis

-   Goal Seek to explore target outcomes
-   Scenario comparison for different sales quantities
-   Linear regression summary to assess the relationship between
    selected variables

## 📊 Dashboard

The **DashBoard** worksheet brings the main performance indicators and
sales breakdowns together in one place. It is designed to make the
results easier to understand and explore.

## 💡 Project Outcome

This project demonstrates how Microsoft Excel can be used beyond basic
data entry --- from cleaning and organising transaction data to
analysing performance and communicating insights through dashboards.

It also provides practical experience with spreadsheet formulas,
business analysis techniques, statistical tools, and data visualisation.
